How it works

It feels like a meeting, not a chat box.

Huddle handles the things that make a group call work: who has the floor, who's talking to whom, and who should stay quiet.

🧑‍🤝‍🧑

Only the people you need

Describe the work and Huddle invites just the teammates it needs, each with matching Claude skills. Or start with one all-rounder that asks before bringing anyone in.

🎯

Only the one you name answers

Start with a name, or name several. “Everyone” or “Does anyone…” asks the room. Without a name, Huddle works out who you meant from the conversation.

“Intern, summarise what we decided.”

💬

Agents think out loud

You hear “Sure, let me look at the code” within a couple of seconds, then short progress updates, then the outcome. Details land in the chat, not in your ears.

✋

One voice at a time

Others raise a hand and wait their turn. Start talking and whoever is speaking stops. Keep talking, and an agent that hasn't started working waits for you to finish.

Features

Your accounts. Your Mac. Your team.

🔑

No API keys

Each teammate runs through Claude Code, Codex or Gemini CLI, signed in with your own account, so your existing plan pays. Or run free local models with Ollama.

🎛️

Model and effort per teammate

Put your Developer on Sonnet and your Intern on Haiku. Change the model or effort mid-call from their tile, and they keep their memory.

🗣️

Natural voices, free

Every teammate gets a human-sounding voice from a neural model running on your Mac. Speech-to-text runs locally too, so it works in Brave, Safari and Chrome.

🪟

Picture-in-picture

Pop the call out into a small window that floats over your editor, just like Meet. It shows who's speaking and has a mic button.

🧾

Part of Claude Code

Install the plugin and Huddle starts on its own. A Huddle row sits above your prompt, calls float in the corner, and Claude can ask your team questions for you.

🔒

Private by default

Everything runs on your machine: the app, the agents, the voices and your transcripts. Huddle only listens on localhost.

Setup

Five minutes to your first call.

Huddle runs on Mac and Windows. You need at least one AI account: Claude (Pro or Max) through Claude Code, or ChatGPT through Codex. Huddle walks you through connecting them the first time it opens.

Already running? Open Huddle ↗

Download and install

Mac · Apple Silicon Mac · Intel Windows

First open on a Mac: right-click Huddle → Open, since it isn't notarized yet. On Windows, if SmartScreen appears: More info → Run anyway.

Connect your AI

Huddle finds Claude Code and Codex on your computer and signs you in with your own Claude or ChatGPT account. No API keys.

Add Huddle to Claude Code (optional)

In Huddle, open Connections → Add to Claude Code. You get a Huddle row above the prompt, a live panel and /huddle. Or from a terminal:

claude plugin marketplace add shivambisen/huddle
claude plugin install huddle@huddle
Run from source instead
git clone https://github.com/shivambisen/huddle
cd huddle && npm install && npm start
# open http://localhost:4317
Questions

Good to know

Why does Huddle run on my computer instead of in the cloud?

Your agents work in your project folders and use the Claude or ChatGPT login on your Mac. A website can't do that safely, so the app runs locally and this site just explains how to get it.

Does it cost anything?

Huddle itself is free. Agents use the plan you already pay for (Claude Pro/Max, ChatGPT Plus/Pro), and voices and speech recognition run locally at no cost.

App or browser?

Either. The Mac and Windows apps include everything. If you run from source, use Chrome, Edge or Brave; Safari works for calls and voice, but pop-out needs a Chromium browser.

How fast do agents respond?

With Sonnet or Haiku at low effort, you hear the first words in about two seconds. Bigger models and higher effort think longer before they speak.

Can agents change my files?

Only if you let them. Each teammate is read-only, can edit files, or has full autonomy, and only inside the team's folder.
